# AIRF 4201 — Airline Operations and Management

Mount Royal University | Aviation Management

This repository holds instructor-provided demonstrations, interactive examples, guided activities, and approved datasets for AIRF 4201.

**No coding or Git knowledge is required for students.** Students run provided Google Colab notebooks, explore outputs, and interpret results to complete activities and assignments. **All coursework is submitted through D2L, not GitHub.** D2L remains the authoritative source for deadlines, instructions, and grades.

## Organization

Within each module, use `examples/` for ready-to-run notebooks, `activities/` for guided exercises, and `data/` for approved small datasets. Create these subfolders **only when content exists**. Reusable code lives in `shared/`; student instructions live in `docs/`.

[Student guide: Open notebooks in Colab](docs/using-colab.md) · [Maintainer content guidelines](docs/content-guidelines.md)

## Scope and privacy

Never upload student submissions, grades, personally identifying data, confidential airline or airport data, instructor solutions, or unreleased assessments here. Keep instructor-only materials in a separate private repository. Teaching examples may use illustrative data and must clearly indicate assumptions and sources.

This repository supplements D2L. Material reuse rights are not yet specified by a license.

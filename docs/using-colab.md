# Student guide: use AIRF 4201 Colab notebooks

You do not need to write code, install Python, or learn GitHub.

1. Follow the notebook link provided in D2L, or browse this repository for your module.
2. Open the notebook in [Google Colab](https://colab.research.google.com/). You can choose **File → Open notebook → GitHub** and paste the GitHub notebook URL.
3. Select **Runtime → Run all**, or run a cell using its play icon, as directed.
4. Change only clearly labelled input values when an activity asks you to explore scenarios.
5. Interpret the output and follow the questions and submission instructions in D2L.

**Submit all assignments through D2L**, not GitHub. If you want to save a personal copy, use **File → Save a copy in Drive** in Colab; this does not submit your assignment.

Some notebooks need an internet connection or a Google account. If a notebook gives an error, share the notebook filename and the error with your instructor.
